# Activity 6.2: Modular Programming & Standard Library Exploration

## 1. Benefits of Modular Programming

**Modular Programming** คือการแบ่งโปรแกรมขนาดใหญ่ออกเป็นส่วนย่อย ๆ เช่น Functions และ Modules เพื่อให้แต่ละส่วนรับผิดชอบงานเฉพาะอย่าง

### ประโยชน์ของ Modular Programming
* **อ่านโค้ดง่ายขึ้น:** การแบ่งโปรแกรมออกเป็นฟังก์ชันทำให้โค้ดแต่ละส่วนมีหน้าที่ชัดเจน และเข้าใจการทำงานได้ง่ายขึ้น
* **นำโค้ดกลับมาใช้ซ้ำได้ (Code Reusability):** ฟังก์ชันที่สร้างไว้สามารถนำไปเรียกใช้หลายครั้ง โดยไม่ต้องเขียนโค้ดเดิมซ้ำ
* **แก้ไขและบำรุงรักษาง่าย (Maintainability):** หากพบข้อผิดพลาด สามารถแก้เฉพาะฟังก์ชันหรือ Module ที่เกี่ยวข้อง โดยไม่จำเป็นต้องแก้ทั้งโปรแกรม
* **ช่วยในการ Debug:** สามารถทดสอบแต่ละฟังก์ชันแยกกัน ทำให้ค้นหาจุดที่เกิดปัญหาได้ง่ายขึ้น
* **เหมาะกับการทำงานเป็นทีม:** สมาชิกแต่ละคนสามารถรับผิดชอบ Functions หรือ Modules คนละส่วน แล้วนำมารวมกันเป็นโปรแกรมเดียว
* **เหมาะกับโปรแกรมขนาดใหญ่:** เมื่อโปรแกรมมีจำนวนโค้ดมากขึ้น การแบ่งออกเป็น Modules จะช่วยให้จัดการโครงสร้างโปรแกรมได้ง่ายขึ้น

### ตัวอย่างจาก Lab 6.2
สร้างไฟล์ `my_utils.py` ซึ่งมีฟังก์ชัน `greet()` และ `is_prime()` จากนั้นนำ Module นี้ไปใช้ใน `main_program.py` ด้วยคำสั่ง `import my_utils` ทำให้สามารถนำฟังก์ชันที่สร้างไว้มาใช้ในโปรแกรมอื่นได้

## 2. Standard Library Exploration

Python มี Standard Library ซึ่งเป็นชุด Module และฟังก์ชันที่มีมาให้พร้อมกับ Python ทำให้เราไม่จำเป็นต้องเขียนทุกอย่างขึ้นมาเอง 

สามารถศึกษาเพิ่มเติมได้จากเอกสารอย่างเป็นทางการ: [Python Standard Library Documentation](https://docs.python.org/3/library/)

### Module 1: `math`
`math` ใช้สำหรับการคำนวณทางคณิตศาสตร์ เช่น รากที่สอง ค่าคงที่ทางคณิตศาสตร์ และฟังก์ชันทางคณิตศาสตร์ต่าง ๆ

**ตัวอย่างจาก Lab 6.2:**
```python
import math

number = 64
result = math.sqrt(number)
print(result)
```

**ผลลัพธ์:**
```text
8.0
```

**ประโยชน์:**
สามารถใช้ในการคำนวณทางคณิตศาสตร์ที่ซับซ้อนกว่าการใช้ Operator พื้นฐาน เช่น การหารากที่สอง หรือการคำนวณทางคณิตศาสตร์อื่น ๆ

---

### Module 2: `random`
`random` ใช้สำหรับสร้างหรือสุ่มค่าต่าง ๆ

**ตัวอย่าง:**
```python
import random

number = random.randint(1, 100)
print(number)
```

**ตัวอย่างผลลัพธ์:**
```text
57
```
*(เมื่อรันอีกครั้งอาจได้ค่าอื่น เช่น `23`)*

**ประโยชน์:**
สามารถนำไปใช้สร้างเกม การสุ่มคำถาม การสุ่มตัวเลข หรือการจำลองเหตุการณ์ที่ต้องการค่าที่แตกต่างกัน

---

### Module 3: `datetime`
`datetime` ใช้สำหรับจัดการวันที่และเวลา

**ตัวอย่าง:**
```python
import datetime

today = datetime.datetime.now()
print("Current date and time:", today)
```

**ตัวอย่างผลลัพธ์:**
```text
Current date and time: 2026-08-18 03:00:00
```
*(เวลาที่แสดงจริงจะขึ้นอยู่กับเวลาที่โปรแกรมถูกรัน)*

**ประโยชน์:**
สามารถนำไปใช้กับโปรแกรมที่ต้องบันทึกวันที่และเวลา เช่น ระบบจองสินค้า ระบบบันทึกข้อมูล หรือโปรแกรมที่ต้องคำนวณระยะเวลาระหว่างวันที่

## สรุป
จากกิจกรรมนี้ ได้เรียนรู้ว่า Modular Programming ช่วยให้โปรแกรมมีโครงสร้างที่เป็นระเบียบ อ่านง่าย แก้ไขง่าย และสามารถนำโค้ดกลับมาใช้ซ้ำได้ นอกจากนี้ Python ยังมี Standard Library จำนวนมาก เช่น `math`, `random` และ `datetime` ซึ่งช่วยลดเวลาในการเขียนโปรแกรม เพราะเราสามารถนำฟังก์ชันที่มีอยู่แล้วมาใช้งานได้ทันที
